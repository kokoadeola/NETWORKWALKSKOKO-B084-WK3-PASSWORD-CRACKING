## 🔑 Exercise 2: Password Cracking with John the Ripper for PDF 1 and 3

## 📌 Exercise Overview
The second supplied completion document confirms that another flag was captured. It specifically refers to password cracking, patience, and the use of the right wordlist. The flag also identifies the exercise with the jtr label, which is consistent with John the Ripper.

John the Ripper is a password-auditing tool that tests candidate passwords against password hashes. A wordlist attack tests entries from a selected list rather than trying every possible character combination.

## 🎯 Objectives
- Understand the basic purpose of password-hash auditing.
- Practise the assigned password-cracking exercise using the provided challenge environment.
- Understand why wordlist selection can affect the outcome of a password audit.
- Capture and document the completion flag.

## 🧰 Tool and Concepts
Item	Description
Tool identified by the completion flag	John the Ripper (JtR)
Exercise category	Password cracking/password auditing
Technique referenced by the completion document	Wordlist-based password testing
Input required in a typical JtR workflow	A supported password-hash file
Output in a successful audit	A recovered candidate password, where the supplied hash and wordlist permit recovery

💡 Learning Outcomes
- Password hashes are not the same as plaintext passwords; password-auditing tools test candidate passwords against hashes.
- Wordlist-based testing depends on the quality and relevance of the candidate list.
- Patience and a methodical approach are important during password auditing.
- John the Ripper provides options for running password audits and reviewing recovered results.
- The hash format and the options supplied to the tool must be appropriate for the input.
